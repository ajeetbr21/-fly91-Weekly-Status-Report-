### Accent bar is now full-height (v1 main issue resolved)

The v1 blocker was that `_set_cell_vertical_bar_height` only cleared run text and never set a height, so the blue bar was a one-line stub. The helper now takes the row as well as the cell and appends a `w:trHeight` to the row's `w:trPr`:

```python
usable_twips = int(9.3 * 1440)  # 13392 twips
tr_pr = row._tr.get_or_add_trPr()
tr_height = OxmlElement("w:trHeight")
tr_height.set(qn("w:val"), str(usable_twips))
tr_height.set(qn("w:hRule"), "atLeast")
tr_pr.append(tr_height)
```

The call site passes `header_tbl.rows[0]`. The generated `word/document.xml` carries exactly one `<w:trHeight w:val="13392" w:hRule="atLeast"/>` and no other `trHeight`, so the single tall row is the cover layout row and nothing else. `hRule="atLeast"` is correct given the right cell holds a 1.8in logo — the row is guaranteed at least the full usable height but can still grow. The height derivation (11in page − 0.9in top − 0.8in bottom = 9.3in) matches the chosen margins. (confirmed)

### Verifier now catches the accent-bar regression
